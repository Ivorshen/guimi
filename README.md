# 诡秘之主2 × 华为｜「灰雾之上」小程序交互 Demo

单文件 HTML 交互 Demo，图片与样式都已内联在文件里，不依赖外部资源。

## 打开方式

- **本地**：直接用浏览器打开 `index.html`
- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后访问 `https://<用户名>.github.io/<仓库名>/`

建议用桌面浏览器打开，左侧是导览栏，可以一键跳转模块和打开各个弹层。

## 预览参数（可选）

在地址后加参数可直接打开指定状态，例如：

- `index.html?p=home` 首页　`?p=event` 事件簿　`?p=shop` 兑换所　`?p=me` 手记
- `?r=1` 入会选途径　`?p=home&x=quiz` 本周挑战　`?p=home&x=game` 消消乐　`?p=home&x=lot` 好运抽卡　`?p=home&x=promote` 晋升特效
